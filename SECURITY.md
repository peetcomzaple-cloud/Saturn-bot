# Security — Saturn bot

This policy applies to the Saturn bot development source in this repository. It does not represent a support commitment from Rakazo or another upstream project.

## Reporting

Do not post credentials, personal data, exploit payloads or unfixed vulnerability details in public issues.

A Saturn-specific private vulnerability-reporting channel has not yet been configured or verified. Before distributing a production release, the maintainer must publish a working private reporting route. Use a private GitHub reporting option only if it is explicitly available on this repository; do not assume an upstream project's mailbox handles Saturn reports.

Non-sensitive general questions can use this repository's issue tracker when available.

## Supported versions

This is a development snapshot. No stable Saturn release or security-response SLA is currently advertised. The validation boundaries are recorded in docs/VALIDATION_STATUS.md. A successful compile is not a security certification.

Third-party model/API and runtime vulnerabilities should follow the relevant provider's own reporting policy. Upstream attribution and licenses remain in NOTICE and PROVENANCE.md.
