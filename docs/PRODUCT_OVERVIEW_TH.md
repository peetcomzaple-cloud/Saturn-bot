# Saturn bot

**ทีม AI ที่คุณเลือกโมเดล ใช้ API key ของตัวเอง และกำหนดพื้นที่ทำงานได้**

Saturn bot เป็นพื้นที่ทำงานสำหรับผู้ช่วย AI หลายตัว ใช้ฐานระบบจาก Rakazo และเพิ่มประสบการณ์ใช้งานแบบ Saturn ทั้งตัวตนดาวเคราะห์ ธีม และหน้าจอที่รองรับภาษาไทย/อังกฤษในส่วนที่ปรับแล้ว

## จุดขายที่อธิบายได้จากโค้ด

- **เลือกผู้ให้บริการและโมเดล:** มีโครงสร้างการเชื่อมต่อโมเดลและการตั้งค่าบัญชี/บอต รวมถึงปลายทางที่รองรับโปรโตคอลที่กำหนด การใช้งานจริงขึ้นอยู่กับ credential และความสามารถของปลายทาง
- **ควบคุมพื้นที่ทำงาน:** โค้ดฐานรองรับการติดตั้งระบบเองและสภาพแวดล้อมคอมพิวเตอร์สำหรับเอเจนต์ การใช้เครื่องแยกช่วยแยกงานจากหน้าจอหลักเมื่อจัดเตรียมและตรวจสภาพแวดล้อมถูกต้อง
- **จัดงานผ่านบอตและบทสนทนา:** ใช้โมเดลข้อมูลและ API จริงสำหรับบทสนทนา ไฟล์ งาน และสถานะ ไม่ได้นำข้อความตอบจำลองจากเทมเพลตดีไซน์มาอ้างเป็น AI จริง
- **ควบคุมต้นทุนได้ละเอียดขึ้น:** มีโค้ดจัดงบ context, จัดการ tool results, ขอใช้ prompt cache ตามความสามารถ และพิจารณาราคา/ชนิดโมเดล กลไกเหล่านี้ยังไม่ใช่หลักฐานว่าใช้โทเคนน้อยกว่าคู่แข่ง
- **ประสบการณ์แบบ Saturn:** ดาว 12 แบบ ตัวเลือก avatar หน้าต้อนรับ และการปรับภาษา/หน้าจอให้เป็นทิศทางเดียวกัน

## เหมาะกับใคร

ผู้ใช้หรือทีมที่ต้องการเลือกผู้ให้บริการเอง มีเครื่องหรือเซิร์ฟเวอร์สำหรับระบบ และยอมรับภาระการตั้งค่า/ดูแลเพื่อแลกกับการควบคุมระบบมากขึ้น

## ขอบเขตที่ต้องบอกตรงไปตรงมา

นี่คือ development snapshot ของ repo ที่แยกใหม่ การมีโค้ดหรือผลตรวจ UI จากต้นทางไม่ยืนยันว่าการติดตั้งใหม่นี้พร้อมใช้งานจริงครบทุกฟังก์ชัน ยังไม่มี benchmark เทียบคู่แข่งเรื่องคุณภาพ ความเร็ว โทเคน หรือต้นทุนต่องานที่สำเร็จ ภาษาไทยบางส่วนยังใช้ข้อความอังกฤษสำรอง

การโฮสต์เองไม่ได้แปลว่าข้อมูลทั้งหมดอยู่ในเครื่องเสมอ ข้อมูลที่ส่งให้โมเดล/API หรือบริการภายนอกยังอยู่ภายใต้นโยบายของบริการที่เลือก ค่า API เครื่องมือ และเครื่องที่ใช้รันอาจเกิดแยกกัน
