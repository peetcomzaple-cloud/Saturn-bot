# Saturn bot brand

Saturn bot is an independently maintained product built on Rakazo. Keep that attribution concise in the README and preserve full source and third-party notices in their dedicated files.

## Palette

| Role | Color | Use |
| --- | --- | --- |
| Midnight navy | `#14213D` | Primary text, strong surfaces, navigation |
| Saturn gold | `#D6A24A` | Logo accents, selected states, primary emphasis |
| Warm ivory | `#FFF9EF` | Light canvas |
| Deep night | `#0B1220` | Dark canvas |
| Accessible dark gold | `#8A5A15` | Gold-toned text on a light surface |

Use navy text on gold controls. Do not use white small text on the gold fill without checking contrast. Gold is an accent, not a replacement for success/warning/error semantics. Runtime UI colors must be semantic tokens from the existing shared TypeScript token source.

The owner-supplied Saturn logo is a friendly golden planet. Reuse the original PNG without changing the artwork. The twelve planet identities remain distinct. Use restrained orbit motion and honor reduced-motion preferences.

Keep layouts calm, legible, and useful. Do not add phone/video controls, decorative dashboards, fabricated savings counters, or features without a working integration.

Native app identifiers are prospective local product identifiers, not proof of registered store/signing identities. Native release and compatibility validation remain separate gates.
